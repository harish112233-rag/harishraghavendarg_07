## 📸 Adding Your Photo

1. Add your photo to the `assets/img/` folder (name it `harish.jpg`)
2. In `index.html`, find this comment:
   ```html
   <!-- REPLACE src WITH YOUR PHOTO: <img src="assets/img/harish.jpg" ...> -->
   <span class="about-avatar-initials">HRG</span>
   ```
3. Replace the `<span>` lines with:
   ```html
   <img src="assets/img/harish.jpg" alt="Harish Raghavendar G"
        style="width:100%;height:100%;object-fit:cover;position:relative;z-index:2;border-radius:2px;">
   ```
